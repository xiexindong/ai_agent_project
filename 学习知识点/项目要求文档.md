## 四、Agent核心四大模块（岗位核心，面试深挖）
### 1. 工具调用 Function Calling（必备）
- 原理：LLM生成函数参数，后端执行工具，返回结果给模型继续思考
- 自定义工具封装：数据库查询、API调用、文件读写、业务系统接口
- MCP协议（Agent工具协议，近年热点）

### 2. RAG 检索增强生成（几乎所有Agent岗位必考）
完整链路：文档加载 → 解析 → 分块Chunk（chunk size/overlap策略）→ Embedding向量化 → 入库 → 检索（向量+关键词混合检索）→ Reranker重排 → 拼接上下文 → LLM生成
面试高频：召回率低怎么优化、RAG幻觉如何处理、RAG vs 微调选型

### 3. 记忆 Memory 机制（重点，你关注的记忆压缩）
- 工作记忆（短期）：当前会话上下文
- 长期记忆：外部数据库存储历史任务、用户信息
- 上下文压缩策略：摘要、截断、向量摘要、记忆分层，解决长对话窗口溢出
- 会话状态持久化

### 4. 任务规划 & Agent推理范式
- ReAct（思考→行动→观察循环，面试最高频）
- Plan & Execute、Reflexion自我反思
- 循环终止策略：最大轮次限制、重复动作检测、超时熔断（防止死循环烧Token）
- Human-in-the-loop 人工介入节点

## 五、Agent开发框架（至少精通1个，了解其他）
