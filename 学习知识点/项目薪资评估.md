## 二、你的项目值多少：一个关键判断

> **这个项目的市场价值，大约等同于「1–2 年商业 AI 应用开发经验」。**

翻译一下：

- 它能让你**跨过"没做过 AI"这道门槛**（很多公司卡的就是这个）
- 它能给报价**加 3–8K/月**
- 但它**不能替代真实的商业年限**——面试官会打折，理由有三：
  1. 没有真实用户流量与线上事故处理经验
  2. 没有团队协作、代码评审、需求妥协的痕迹
  3. 没有效果和成本的量化数据（你说好，怎么证明）

**这就是"能力值"和"能拿到"的差距**：你的能力上限可能在 30K，但没有年限背书时，实际拿到 20–25K 是正常的。

## 五、怎么谈（实操建议）

**1. 别先报数字。** 被问期望薪资时，回："我更想先了解岗位的具体方向，薪资按市场水平来，我这边灵活。" 让 HR 先出价。

**2. 报区间就报上限。** 如果你真实想要 25K，报"25–30K"。HR 永远取下限。

**3. 用项目证明"我能讲清为什么"，不是"我做了很多"。** 面试里最有杀伤力的是这五个：

- 为什么自研 MCP 不用 SDK → 讲 stdio 传输、两段握手、管道堵塞
- 为什么自己算余弦不用向量库 → 讲规模与 IVF 近似 vs 全量精确
- 为什么缺变量抛错而不是填空 → 讲"静默降质"
- token 超预算按什么顺序丢 → 讲权限 > 工具 > 观察 > … 和 50 token 阈值
- 技能三级路由为什么这么分 → 讲代价递增与降级链

**能讲清 why 的人，和只会堆功能的人，报价差 5–10K。**

**4. 投对地方。** 你的画像最适合：

| 优先级 | 目标 | 理由 |
|---|---|---|
| ★★★ | AI 应用层创业公司 / 中小厂 AI 平台团队 | 认能力、认项目、决策快，能给到 25–35K |
| ★★★ | 传统行业数智化 / ToB SaaS（企业助手方向） | 你的**权限 + 审计 + 脱敏 + 风控**正好对口，这是你相对其他候选人的护城河 |
| ★★ | 中厂 AI 中台 | 流程规范，但更看学历年限 |
| ✗ | 大厂算法岗 / 模型训练岗 | 要论文与训练经验，别浪费时间 |

## 六、最快提升报价的两件事

**① 花 1–2 天加一套评测集**（30–50 条问答 + 自动跑分）
这是性价比最高的一步。有了它，简历上能写"建立自动化回归评测，改动可量化验证"——**这一条能把你的档位从"1–3年"推向"3年+"的话术空间**，面试通过率也明显提升。

**② 补一份性能与成本报告**
并发 10/50 下的 P95 延迟、单轮平均 token 与成本。哪怕单机数据，也能把"我做过"变成"我测得出来"。

这两件做完，你的报价上限能往上抬 **3–5K**。
